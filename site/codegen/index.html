Gooo Go Ports · Experimental

Edit Gooo, generate Go

Edit a single-file Gooo source and generate Go for one activity. The pinned Gooo compiler library runs locally in your browser.

This generates Go; it does not run the generated program. Package imports and model-backed generation are unavailable here. The first load downloads about 22 MB.

Selecting a saved sample preloads its source. You can edit it below; samples themselves stay unchanged.

The compiler pin and bridge hash identify the compiler checkout and this separate browser bridge. They do not overwrite the engine's UNBOUND_LOCAL_SOURCE receipt. Input edits and new requests immediately clear previous output and reports.

      
The worker loads only local static assets and has no filesystem access supplied by this page. Compiler initialization expires after 60 seconds; generation expires after 15 seconds and terminates the worker.
