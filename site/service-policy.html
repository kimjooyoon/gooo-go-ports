Read the result

        
Request matching answers for one request. A valid input can return matched: false. Request comparison describes only that same request before and after. Grant comparison examines the relationship between two supported patterns and can return a concrete request admitted only by the proposal.

        
For mcp://*.x → mcp://a.*, both patterns admit mcp://a.x. Grant comparison finds mcp://a.y, which only the proposal admits. Recognized subset rules establish their bounded pattern relationship; an UNPROVEN result cannot establish a subset.

        
Use semantic fields only after domain_status: VALID_INPUT. The supported domain uses ASCII service types and dotted names with the documented wildcard forms. A complete Agent Mesh policy can contain additional grants, HTTP restrictions and other rules. Actual automatic updates require an authenticated host that checks current authority and policy version at its commit boundary.

        
Inputs stay in this browser. The page fetches only static program and source assets and stores no input history. Gooo implements the decisions; JavaScript transports inputs and displays results.
