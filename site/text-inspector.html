Offsets start at zero in the received UTF-16 sequence. Encoding lengths come from Go’s RuneLen functions: −1 means the value cannot be encoded as a Unicode scalar. A lone surrogate occupies one received code unit but has encoding length −1.

Go White_Space membership does not describe how a character looks. This view reports code points, not user-perceived character boundaries.

Four Gooo calls for each row.

The browser decodes its UTF-16 input and passes each decimal value to the existing compiled utf8.ValidRune, unicode.IsSpace, utf8.RuneLen and utf16.RuneLen ports. A dedicated worker runs the same WebAssembly program as the function demo. No arbitrary text is passed to a Gooo string-processing function.
