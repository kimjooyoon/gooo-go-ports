Search rules

        
Index returns the first matching UTF-8 byte offset, or -1 when absent. For example, finding x in 가x가 returns byte offset 3. A byte offset is not a JavaScript character index.

        
Count counts non-overlapping occurrences. An empty needle has first offset 0 and count equal to the number of Unicode code points in the bound text plus one. Combining marks and emoji sequences may contain several code points. Search is literal and case-sensitive; it does not apply regular expressions, grapheme segmentation or normalization.

        
The page runs the compiled Gooo Report activity in a Worker after verifying its WebAssembly byte count and SHA-256 against the build manifest. Input conversion and transport validation use JavaScript; search and count come from the compiled ports.
