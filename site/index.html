MEET THE LANGUAGE

          
What is Gooo?

          
Gooo names data types as entity declarations and typed operations as activity declarations. Explicit IDs connect declarations to generated code and execution records.

          
package checker
namespace checker
import utf8 "go/unicode/utf8"
entity Integer id "gooo://std/integer"
entity Boolean id "gooo://std/boolean"
activity Valid(Integer) -> Boolean id "gooo://example/checker/valid" computes `return utf8.ValidRune(input)`

          
Valid takes an Integer and returns a Boolean. Its computes body calls the imported Unicode port. The complete guide includes the workspace, inputs, and saved replay.

          
For a graphics example, read how subpixel bounds become pixel coordinates, including empty selections and the original Go ceiling overflow.
