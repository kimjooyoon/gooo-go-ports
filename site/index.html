WHAT YOU ARE RUNNING

          
A fixed set of real functions.

          
The calculations are written in Gooo and compiled ahead of time. This demo runs those functions; it does not compile arbitrary Gooo source.

          
These are selected function ports, not complete HTTP, Unicode, byte, or color packages. Passing finite reference cases is evidence for those cases, not a proof of full compatibility.
