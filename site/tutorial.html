1 / CHOOSE YOUR INPUTS

An exact signed 64-bit decimal integer, from -9223372036854775808 to 9223372036854775807. No rounding or truncation.

Text is used without trimming. In JSON string mode, include double quotes; for example "line\r\nnext\u0000".

See the label passed to Gooo 

            
This JSON view shows CR, LF and NUL as escapes. Other Unicode characters may remain invisible. A normal text editor may convert CR/CRLF to LF; JSON string mode preserves explicit escapes. Native JSON decoding replaces unpaired UTF-16 surrogates with U+FFFD. Valid pairs, BOMs and combining marks are preserved.

            
The label input and returned Text each allow up to 1,024 UTF-8 bytes. The program adds : low or : high, so a long accepted input can still produce an output-limit error. Inputs are never shortened to make them fit.
