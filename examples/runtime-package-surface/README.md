# Keep a runtime package rule in Gooo

The recorded-catalog application has eight declared non-standard Go packages.
Three repository verifiers used to repeat that list. Their expectation now lives
in [`Inspect`](../../ports/runtime-package-surface/inspect.gooo), and each verifier
passes its own `go list` observation to the same generated evaluator.

This is a development-time dependency check. Gooo calculates membership,
missing and undeclared counts, repetition, and the assessment status. The Go
command handles JSON; the Python adapter binds the observation to the original
command output. The application does not import this checker, so adding the
checker does not expand the package surface it measures.

## Run an observation

With Go 1.27.3 installed, pass an observation from the repository root:

```sh
GOTOOLCHAIN=local GOWORK=off go run ./cmd/check-runtime-package-surface \
  < observation.json > assessment.json
```

The input has two fields:

```json
{
  "origin_ref": "sha256:<digest of the retained original go-list stdout>",
  "import_paths": ["an exactly observed import path"]
}
```

The example above is a shape example, not an exact observation of this program.
Collect non-standard imports inside the application module using
`go list -deps -f '{{if not .Standard}}{{.ImportPath}}{{end}}' ./cmd/compare`.
Retain its command, source revision, Go version, working directory, build context
and raw stdout. Preserve the order, duplicates and spelling of nonempty lines.
A tagged or cross-platform build needs its own observation.

The command and repository adapter accept at most 256 paths, 1,024 UTF-8 bytes
per text value, and 512 KiB of input. These are adapter resource limits. They do
not restrict the Gooo language's text domain: spaces, Unicode, case, repetitions
and carriage returns are preserved, and no import-path grammar is imposed.

`origin_ref` is an opaque input to Gooo. The adapter binds it to retained bytes;
the language does not authenticate the producer from that string. Read the
assessment, not just the process exit code. `OBSERVED_EXACT` means that the saved
package observation matches this declaration. It does not approve a version
upgrade or authorize a deployment.

## Check the rule and detect drift

The declaration in `ports/runtime-package-surface/inspect.gooo` and its upstream
hashes are pinned together. [`cases.json`](cases.json) stays independent: it
contains fourteen complete expected
assessments, including reordered, missing, unknown, repeated and empty paths,
and missing origins. Do not derive the declaration or expected assessments from
the latest `go list` output. An intentional rule update needs a reviewed upstream
revision (or a separately documented downstream adaptation), updated independent
expectations and fresh generated evidence. Do not overwrite the upstream hashes
to label an edited file as unchanged upstream source.

Using the repository's pinned compiler and Go 1.27.3, run:

```sh
python3 -I -B examples/runtime-package-surface/verify.py \
  --compiler "$PWD/.gooo" --go "$(go env GOROOT)/bin/go" \
  --go-cache "$(go env GOCACHE)" --module-cache "$(go env GOMODCACHE)" \
  --out /tmp/gooo-runtime-surface-check
```

Choose a new output directory for each run. The verifier checks fourteen native
results and their own replay, then changes the declaration in two separate
copies while keeping the expectations fixed. Each changed copy must mismatch
all fourteen expectations. Those mutation receipts have `PROGRESS` and exit
zero; they are not a passing fixture result.

Generation binds the Gooo sources, typed field identities, fixtures, compiler,
Go toolchain, original execution and replay to the four generated files. The
saved PROV-O graph records those dependencies. The normal check compares fresh
generated bytes with the committed files. The initial `--bootstrap` mode requires
all four generated files to be absent and never overwrites a partial generation.

The product's runtime generations and distribution file inventory have separate
purposes. This root verifier is not another runtime kernel in the distributed
recorded-catalog command.

## Source and limits

The two Gooo files and fourteen fixtures are preserved from
[`meta-ontology-go` at `2a69071`](https://github.com/kimjooyoon/meta-ontology-go/tree/2a69071552a944be597d86fdd34041ea344cdce0/examples/runtime-package-surface).
Only the workspace source locations are adapted. The original MIT notice is in
[`ports/runtime-package-surface/LICENSE`](../../ports/runtime-package-surface/LICENSE);
[`upstream.json`](upstream.json) records the immutable source hashes.

This repository independently uses compiler
`205896a413e5dea92366309c35ae85e542d055f6` and Go 1.27.3. A newer upstream source
commit does not change that compiler pin or inherit its execution results.
Finite fixture success is not proof for every possible dependency observation.
